# 03. Router и современные маршруты ServeMux

## 03.1 Список заметок

**Что тренируем.** Регистрацию method и path как одного маршрута.

**Как рассуждать.** В `NewRouter` свяжите строку `"GET /notes"` с `h.ListNotes`. Читайте её как предложение: «GET-запрос по точному path `/notes` вызывает ListNotes».

**Мини-пример.** `GET /notes` подходит, `POST /notes` к этому маршруту не подходит.

**Частая ошибка.** Зарегистрировать только `"/notes"` и затем писать большой if по `r.Method`.

**Как проверить.** `go test ./internal/httpapi -run TestGetEmptyList` после раздела 04.

## 03.2 Одна заметка и wildcard

**Что тренируем.** Сегмент `{id}` в современном ServeMux.

**Как рассуждать.** Зарегистрируйте `"GET /notes/{id}"`. Фигурные скобки означают один именованный сегмент path; значение станет доступно через `r.PathValue("id")`.

**Мини-пример.** `/notes/42` даёт `id == "42"`; `/notes/42/edit` уже не подходит.

**Частая ошибка.** Использовать старый префикс `/notes/` и вручную обрезать строку path.

**Как проверить.** После раздела 04: `go test ./internal/httpapi -run TestInvalidID`.

## 03.3 Создание

**Что тренируем.** Отдельный маршрут для POST.

**Как рассуждать.** Свяжите `"POST /notes"` с `h.CreateNote`. Method является частью договора: тот же path ведёт к другой функции, чем GET.

**Мини-пример.** Router выбирает CreateNote до того, как handler начнёт читать body.

**Частая ошибка.** Пытаться читать body в router: router только выбирает функцию.

**Как проверить.** После раздела 05: `go test ./internal/httpapi -run TestPostValid`.

## 03.4 Частичное изменение

**Что тренируем.** Сочетание PATCH и path parameter.

**Как рассуждать.** Зарегистрируйте `"PATCH /notes/{id}"` для `h.PatchNote`. Идентификатор находится в path, а новые значения — в JSON body.

**Мини-пример.** `PATCH /notes/1` + `{"text":"ready"}` выбирает заметку 1 и меняет только text.

**Частая ошибка.** Искать ID в JSON body: два источника ID могут противоречить друг другу.

**Как проверить.** После раздела 06: `go test ./internal/httpapi -run TestPatch`.

## 03.5 Удаление

**Что тренируем.** DELETE как отдельную операцию API.

**Как рассуждать.** Зарегистрируйте `"DELETE /notes/{id}"` для `h.DeleteNote`. Body для этого запроса не нужен: объект однозначно выбран path.

**Мини-пример.** `DELETE /notes/1` удаляет одну заметку, а не весь список.

**Частая ошибка.** Зарегистрировать `DELETE /notes` и ожидать ID из пустого body.

**Как проверить.** После раздела 06: `go test ./internal/httpapi -run TestDelete`.
